What this release proves

  1. Compile: input/output descriptions become a versioned manifest with readable steps and policy.
  2. Approve: a short-lived approval is cryptographically bound to the manifest hash.

  4. Preserve notes: Markdown uses Logseq properties, tags, nested blocks, and stable IDs.
